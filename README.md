# NULL Pointer Safety Check in C

## Description
This program demonstrates how to safely check whether a pointer is NULL before dereferencing it.

A NULL pointer does not point to a valid memory location. Dereferencing a NULL pointer can cause a program to crash.

## Concepts Used
- Pointers
- NULL pointer
- Address operator (`&`)
- Dereference operator (`*`)
- NULL pointer checking
- Safe pointer usage
